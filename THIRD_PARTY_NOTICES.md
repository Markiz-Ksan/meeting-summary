# Сторонние компоненты

CC0 применяется к собственному коду, документации и графике этого проекта. Она не заменяет лицензии сторонних компонентов.

| Компонент | Назначение | Условия и источник |
| --- | --- | --- |
| MLX / MLX-LM | Локальный вывод на Apple Silicon | [MLX](https://github.com/ml-explore/mlx), [MLX-LM](https://github.com/ml-explore/mlx-lm), лицензии upstream |
| parakeet-mlx | Распознавание речи | [upstream](https://github.com/senstella/parakeet-mlx), лицензия upstream |
| Parakeet TDT 0.6B v3 MLX 4-bit | Весá ASR, скачиваются отдельно | [карточка модели](https://huggingface.co/animaslabs/parakeet-tdt-0.6b-v3-mlx-4bit), CC BY 4.0 по карточке |
| Qwen3.5 9B MLX 4-bit | Весá модели сводки, скачиваются отдельно | [карточка модели](https://huggingface.co/mlx-community/Qwen3.5-9B-4bit), Apache 2.0 по карточке |
| Python-пакеты | Зависимости обработчиков | Зафиксированы в `requirements.lock`; сохраняют собственные лицензии |
| macOS SDK и системные фреймворки | Звук и интерфейс | Предоставляются Apple и в исходники проекта не включены |

В тестовом архиве сохранён синтетический WAV из локального прототипа, также находящийся в `tests/meeting-sample.wav`. Это не запись реальной встречи. Разрешение на его публичное распространение под CC0 не заявляется: перед общедоступным релизом демонстрационный материал должен быть заменён или его права подтверждены. Текущий комплект предназначен для приватного тестирования.

Весá моделей, установленные Python-пакеты, закрытые ключи и сертификаты в виде файлов в репозиторий не включаются. Тестовый `.app` сохраняет свою исходную встроенную подпись; это не передача ключа подписи.
