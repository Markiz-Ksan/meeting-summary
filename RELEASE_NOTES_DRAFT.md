# 0.7.0 beta — проект описания релиза

Это проект текста, а не свидетельство опубликованного или полностью проверенного релиза.

- Полная аудиозапись и полный TXT в одной папке дня; общие время, тема и уникальный ID в имени пары. В TXT сохранены ссылка на аудио и приблизительные временные отметки.
- Отдельное пятиминутное окно краткой сводки, сохранение предыдущей допустимой сводки при отклонении черновика.
- Восстановление обработки и ограниченные ожидания зависших процессов. Фактические сценарии должны подтверждаться программными и отдельными аппаратными проверками.
- Переносимая Apple Silicon сборка для macOS 14.4+: Python и зависимости внутри, автоматическая загрузка закреплённых моделей с SHA-256. Профиль 9B — основной для 16 ГБ+, 8 ГБ не проверены; 4B остаётся экспериментальным вариантом для меньшей памяти.
- Первый Linux-порт для Ubuntu/Debian x86_64: прозрачное окно, трей и видимое управление, PulseAudio/PipeWire-Pulse, CPU Parakeet ONNX и Qwen3.5-9B GGUF, DEB/AppImage. До успешного CI с настоящими моделями и проверки готовых пакетов не считать Linux готовым.
- Windows отложен.

Ограничения: смысловая точность и длительные реальные встречи ещё не прошли полную приёмку; чистая установка и физический Mac с 8 ГБ не подтверждены. Для обычного распространения через Gatekeeper нужны Developer ID Application и нотарификация Apple. Пока нет подтверждённого результата, не указывать «нотарифицировано» или «готово для любого Mac».
