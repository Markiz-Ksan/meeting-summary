# Данные и локальная обработка

- Запись начинается по команде пользователя. Обычное открытие приложения не запускает захват.
- В режиме «Звук Mac» приложение не открывает микрофон. Оно получает внутренний выходной звук; голос, воспроизводимый другим приложением, уже входит в этот поток.
- Обработка речи и сводки выполняется на Mac. Рабочие обработчики включают офлайн-режим Hugging Face; сетевой API для встреч не используется.
- Первичная загрузка Python-зависимостей и моделей обращается к их поставщикам.
- Полная расшифровка хранится в `~/Documents/Расшифровки встреч`. Приложение не удаляет пользовательские TXT при остановке или обновлении.
- Необработанные аудиофрагменты остаются в локальной очереди до подтверждения сохранения текста. После сбоя они могут сохраняться для восстановления.
- Диагностический журнал рассчитан на метаданные и ограничен по размеру. В нём не должны появляться содержание разговора, аудио или сводки.
- Репозиторий не содержит пользовательских встреч, сохранённых разрешений, токенов или моделей.

Записывайте встречи с учётом согласия участников и правил используемой площадки. Автоматический сквозной аудит сетевой активности текущей версии пока не завершён.
