# Участие

В изменении укажите проблему, результат и выполненные проверки.

    PYTHON=python3 /bin/sh scripts/check.sh

Команда запускает программные тесты без моделей и звуковых устройств. Изменения сохранения данных, источников звука и восстановления сопровождайте регрессионной проверкой.

Для изменений сводки отдельно проверяйте факты, условия, отрицания и сроки. Отложенный набор не используйте для настройки.

Не добавляйте личные записи, модели, ключи или пароли. Собственные материалы — под [CC0](LICENSE); для чужих сохраняйте лицензии.
