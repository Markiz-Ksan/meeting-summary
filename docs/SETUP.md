# Установка и сборка тестового снимка

Целевая система — macOS 14.4+ на Apple Silicon. Разработческий компьютер: 24 ГБ объединённой памяти. Работа с меньшей памятью и чистая установка на другом Mac ещё не подтверждены. Нужны Xcode Command Line Tools и Python 3.12. Ниже — ручная настройка; команды загрузки моделей в рамках подготовки репозитория не запускались.

## 1. Python и зависимости

Рабочая среда хранится вне репозитория. Путь содержит пробелы, поэтому кавычки обязательны.

```sh
RUNTIME="$HOME/Library/Application Support/MeetingOverlay/runtime"
mkdir -p "$RUNTIME"
python3.12 -m venv "$RUNTIME/.venv"
"$RUNTIME/.venv/bin/python" -m pip install -r requirements.lock
```

`requirements.lock` — снимок зависимостей существующей рабочей среды. Полная установка этого снимка на чистом Mac пока не проверена. Не заменяйте действующую среду с пользовательскими данными, пока не сохранена её резервная копия.

## 2. Модели

Рабочий код ожидает следующие каталоги:

```text
~/Library/Application Support/MeetingOverlay/runtime/models/
  speech-4bit/     config.json, model.safetensors, ...
  summary-9b/      config.json, tokenizer.json, model-*.safetensors, ...
```

Формат моделей: MLX, 4-bit, group size 64. Совместимые исходные карточки:

- [Parakeet TDT 0.6B v3 MLX 4-bit](https://huggingface.co/animaslabs/parakeet-tdt-0.6b-v3-mlx-4bit).
- [Qwen3.5 9B MLX 4-bit](https://huggingface.co/mlx-community/Qwen3.5-9B-4bit).

Если модели уже подготовлены, используйте их без повторной загрузки. Для новой среды после ознакомления с лицензиями моделей загрузка выполняется отдельно:

```sh
RUNTIME="$HOME/Library/Application Support/MeetingOverlay/runtime"
"$RUNTIME/.venv/bin/hf" download animaslabs/parakeet-tdt-0.6b-v3-mlx-4bit   --local-dir "$RUNTIME/models/speech-4bit"
"$RUNTIME/.venv/bin/hf" download mlx-community/Qwen3.5-9B-4bit   --local-dir "$RUNTIME/models/summary-9b"
```

Это ссылки на внешние модели, а не обещание побайтно идентичной копии среды прототипа. Совместимость свежих загрузок и полного установочного пути ещё требует отдельной проверки. Сама программа обрабатывает только текстовый режим Qwen, без анализа изображения.

## 3. Проверка исходников и сборка

```sh
PYTHON=python3.12 /bin/sh scripts/check.sh
MEETING_BUILD_ONLY=1 /bin/sh build.sh
```

`check.sh` не включает модели, захват и воспроизведение. Сборка только компилирует пакет в корне проекта.

Для установки используйте собственную идентичность подписи:

```sh
MEETING_SIGN_IDENTITY='ВАША_ИДЕНТИЧНОСТЬ_ПОДПИСИ' PYTHON=python3.12 /bin/sh build.sh
```

Ключи, пароли и идентичность автора этого проекта не включены. Для собственного локального тестирования предусмотрена явная разовая ad-hoc установка: `MEETING_ALLOW_ADHOC=1`. Смена идентичности подписи может потребовать повторных разрешений macOS. При обновлении используйте одну идентичность подписи.

Установщик копирует приложение в `~/Applications` и обработчики в `~/Library/Application Support/MeetingOverlay/src`; модели, среда Python и TXT не заменяются. Старые приложение и обработчики сохраняются рядом в `.meeting-install-*`. Квитанция содержит точные пути копий и хеши модулей. Обрабатываемый сбой вызывает общий откат; восстановление после отключения питания или SIGKILL пока ручное.

## 4. Использование готового тестового архива

После подготовки Python и моделей распакуйте `dist/MeetingSummary-0.6.4-test.zip` во временную папку. Внутри находятся подписанное приложение и `workers/`. Установите их тем же проверяющим установщиком:

```sh
python3.12 scripts/install_release.py   '/путь/к/распакованной/Сводка встречи.app'   "$HOME/Applications/Сводка встречи.app"   '/путь/к/распакованной/workers'   "$HOME/Library/Application Support/MeetingOverlay/src"
```

Закройте приложение перед заменой файлов. Тестовая подпись не является Apple-нотаризацией; чистый путь установки вне среды разработчика пока не принят. Не отключайте защиту системы ради непроверенной сборки.

## 5. Первый запуск

В строке меню выберите «Звук Mac», «Микрофон» или «Звук Mac + микрофон», затем «Начать». Разрешения на звук и микрофон выдаются macOS отдельно. Работа источника подтверждается фактическим результатом, а не только включённым переключателем разрешения.

При первом знакомстве можно выбрать «Проверить отображение»: это пример без аудио и моделей. Обычное открытие не начинает запись.
