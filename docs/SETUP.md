# Установка

## Mac

1. Скачайте Mac ZIP из [Releases](https://github.com/Markiz-Ksan/meeting-summary/releases).
2. Распакуйте архив и перенесите «Сводка встречи.app» в «Программы».
3. Откройте приложение и дождитесь загрузки моделей. При первой подготовке нужны интернет и около 13 ГБ свободного места.
4. Выберите источник звука, выдайте запрошенные разрешения macOS и начните запись.

Приложение не нотарифицировано: macOS может потребовать ручного разрешения запуска. Само открытие приложения не начинает запись.

## Linux

Скачайте DEB или AppImage. Команды установки — в [linux/README.md](../linux/README.md).

Полные WAV и TXT сохраняются по датам в «Документы/Сводка встреч».
