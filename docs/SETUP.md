# Подготовка и установка кандидата

Готовая переносимая macOS-сборка предназначена для Apple Silicon/macOS 14.4+. Python и зависимости входят в ZIP; закреплённые модели загружаются при первой подготовке. Разрешения на системный звук и микрофон выдаются macOS отдельно. Открытие приложения не начинает запись.

Сборка разработчиком, модели, подпись и известные ограничения подробно описаны в [packaging/README.md](../packaging/README.md). Основной профиль 9B рассчитан на 16 ГБ и более; физические 8 ГБ не проверены. Модели и настройки уже работающего приложения сохраняются отдельно.

Для обычного распространения требуется Developer ID Application и нотарификация Apple. Наличие ad-hoc либо Apple Development подписи не означает доверенный установщик.

Linux: [linux/README.md](../linux/README.md). Windows отложен. Готовность Linux подтверждается реальным CI-прогоном моделей, захвата и сохранённых пакетов.

Для разработки на Mac:

```
PYTHON=python3 /bin/sh scripts/check.sh
MEETING_BUILD_ONLY=1 /bin/sh build.sh
```

Вторая команда только компилирует кандидат без установки и аудиотеста. Полную переносимую поставку создаёт отдельный `scripts/package_macos.py`; обычный `build.sh` рассчитан также на существующую локальную среду разработчика.
