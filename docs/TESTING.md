# Проверки

Программные тесты macOS:

    PYTHON=python3 /bin/sh scripts/check.sh

Linux:

    python3 -m unittest discover -s linux/tests -v
    QT_QPA_PLATFORM=offscreen python3 linux/entrypoint.py --gui-smoke

Обычные проверки не загружают модели и не открывают аудиоустройства. Виртуальные источники Linux включаются отдельным сценарием CI.

Сборка 18 прошла упаковку, проверку импортов, Linux-интерфейса и установки пакетов. Модельные прогоны и реальное аудио для неё не запускались.

Точность, задержку, память, длинные встречи, сон и Bluetooth проверяют отдельно. [Набор для оценки сводки](../tests/fixtures/acceptance-v1/README.md) содержит 22 примера разработки и 8 отложенных; отложенные примеры не используют для настройки.
