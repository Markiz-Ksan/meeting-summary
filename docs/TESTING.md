# Проверки и границы результата

## Программные проверки

`PYTHON=python3 /bin/sh scripts/check.sh` выполняет Python unit tests и семь Swift-наборов: давность, отправка сводок, контроллер источников, микшер, PCM, дисковая очередь и взаимодействие с обработчиком. Реальные аудиоустройства и модели не открываются.

Проверки установщика работают во временных каталогах. На macOS один сценарий подписывает временные пакеты ad-hoc, портит ресурс после замены и проверяет восстановление прежнего подписанного пакета. Закрытый ключ разработчика не требуется.

Число тестов этого стабильного снимка отличается от локальной экспериментальной ветки: проверки неустановленных валидаторов сюда не включены.

Для подготовленного снимка 2 ноября 2026 выполнены все 65 Python-проверок и семь Swift-наборов; сборка с переносимыми путями также завершилась успешно. Эти результаты получены локально; GitHub Actions ещё не запускался.

## Что подтверждено для 0.6.4

- Сборка нативного приложения.
- Сохранение прежних обработчиков при обновлении; валидность подписи нового и резервного пакетов.
- Короткие реплики проходят политику отправки; два простых текста дали сводку через реальный локальный обработчик.
- Запуск установленного окна на синтетическом примере без аудио.

## Что ещё не принято

- Один из трёх дополнительных коротких текстов был отклонён валидатором.
- Полная смысловая точность на корпусе с отложенной частью и проверкой человеком.
- Задержка от реальной реплики до окна, общий RSS и двухчасовая устойчивость финальной версии.
- Сохранение TCC после последовательных обновлений, сон, Bluetooth и другие устройства.
- Чистая установка и проверка на чужом Mac.

В `tests/fixtures/acceptance-v1` находятся искусственные примеры и заранее составленная разметка. Наличие набора не означает прохождения приёмки. `scripts/evaluate_summaries.py` по умолчанию запускает только development; отложенная часть требует отдельной фиксации обработчика и положительной проверки разработки. Модели не загружаются обычным `check.sh`.

Прошлые аппаратные проверки предшествующих версий не заменяют приёмку 0.6.4. Пользовательские записи и машинные журналы намеренно отсутствуют в репозитории.
