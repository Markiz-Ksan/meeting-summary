# Архитектура

Python ведёт полный транскрипт, пятиминутный контекст, проверку сводки и название встречи.

- **macOS:** Swift/AppKit, Core Audio Process Tap для системного звука, AVFoundation для микрофона, MLX для моделей.
- **Linux:** PySide6, FFmpeg и PulseAudio/PipeWire-Pulse; Parakeet через sherpa-onnx, Qwen через llama.cpp.

Полный WAV записывается до распознавания. Дисковая очередь и отдельные обработчики сохраняют текст независимо от скорости сводки. Watchdog ограничивает зависания и запускает восстановление.

WAV и TXT получают общее имя в папке дня. Модели и настройки платформ хранятся отдельно.
